# e-Verify-Metrology

A comprehensive Legal Metrology digital verification and compliance monitoring web application.

## Overview
e-Verify Metrology provides tools for consumer verification, officer inspection workflows, vendor compliance tracking, and automated certificate generation for legal metrology standards.

## Tech Stack
- **React 19**
- **Vite**
- **Lucide Icons**
- **Vanilla CSS (Modern UI / Glassmorphism)**

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

### Building for Production
```bash
npm run build
```
